# DomEase website and admin

The DomEase landing page (domease.app) and the admin dashboard that runs the mobile app (`/admin`). React 19, Vite, Tailwind CSS 4, React Router and TanStack Query.

```bash
npm install
npm run dev      # site at http://localhost:5173, admin at /admin
npm run lint     # ESLint plus the dash check
npm run build
```

With no `VITE_API_URL` (see `.env.example`) the admin runs on demo data. Sign in as `pearl@domease.app`, password `domease-demo`.

Start with [docs/README.md](docs/README.md).
