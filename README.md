# DomEase website

The DomEase landing page (domease.app). React 19, Vite, Tailwind CSS 4 and React Router.

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint     # ESLint plus the dash check
npm run build
```

Start with [docs/README.md](docs/README.md).
